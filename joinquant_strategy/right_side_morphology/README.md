## `weekly_select.py`

**右侧形态学每周选股 / Right-Side Morphology Weekly Select**

每周第一个交易日晚上运行，基于当日数据筛选「放量启动 → 缩量整理」形态股票，输出本周推荐池与行业分类。默认只打日志，不自动下单。

### 调度时段

| 时间 | 函数 | 作用 |
|------|------|------|
| 每周第 1 个交易日 `night`（约 20:00） | `weekly_select` | 执行选股并打印推荐池 |

说明：聚宽 `run_weekly` 的 `weekday` 表示**本周第几个交易日**（`1` = 本周第 1 个交易日，通常周一），不是日历星期几。

### 选股流程

#### 基础过滤

1. 流通市值 ≥ 下限（默认 50 亿，暂不设上限）  
2. 剔除 ST、科创板、创业板、北交所  
3. 近 20 日日均成交额 ≥ 2 亿（剔除僵尸股）  

#### 核心形态

1. **锚定日 T**：在倒退前 10 个交易日（不含最新日）中，须有一天涨幅 > 5% 且成交量 > 60 日均量 × 2；否则剔除  
   - T 不能是最新交易日，否则后续缩量/收盘约束无法检验  
2. **T 日之后至数据日**须同时满足：  
   - 每日收盘 ≥ T 日开盘  
   - 每日量能 < T 日量能 × 70%  
   - 每日涨幅 ≤ 2%  

### 输出内容

- 全部入选个股列表（含前收、锚定日、T 开盘、T 涨幅）  
- 按申万一级行业分类汇总（含流通市值；标注 <50 亿 / >500 亿）  
- 一行汇总，便于复制  

### 主要函数

| 函数 | 说明 |
|------|------|
| `initialize` | 基准、参数与 `run_weekly` 定时任务 |
| `weekly_select` | 每周选股入口：建池 → 筛选 → 日志输出 |
| `get_stock_pool` | 流通市值与板块基础过滤 |
| `filter_stocks` | 流动性 + 锚定日形态筛选 |
| `print_by_industry` | 按申万一级行业分类打印 |

### 关键参数（`g.*`）

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `min_circ_mv` / `max_circ_mv` | 50亿 / `None` | 流通市值下限 / 上限（`None`=不设上限） |
| `min_avg_amount` / `avg_amount_days` | 2亿 / 20 | 日均成交额下限与统计天数 |
| `top_n` | `None` | 输出只数上限（`None`=全部打印） |
| `anchor_lookback` | 10 | 锚定日回看交易日数（不含最新日） |
| `anchor_gain_min` | 5% | 锚定日涨幅下限 |
| `vol_ma_days` / `anchor_vol_mult` | 60 / 2.0 | 量能均线天数与锚定日放量倍数 |
| `post_vol_max_ratio` | 70% | T 日后每日量能相对 T 日上限 |
| `post_gain_max` | 2% | T 日后每日涨幅上限 |

### 使用注意

- 回测/模拟频率选**日**即可  
- `run_weekly(weekday=1, time='night')`：本周第一个交易日晚上 20:00 执行
