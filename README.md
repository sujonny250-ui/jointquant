# code_repo

聚宽（JoinQuant）量化策略代码仓库。按策略风格分子目录管理，脚本可直接复制到聚宽研究/回测/模拟环境运行。

## 目录结构

```text
code_repo/
└── joinquant_strategy/                 # 聚宽策略根目录
    └── small_cap/                      # 小市值（Small Cap）风格策略
        └── margin_leverage_strategy.py # 小市值融资杠杆策略
```

### 分层说明

| 层级 | 路径 | 含义 |
|------|------|------|
| 仓库根 | `code_repo/` | Git 仓库根目录 |
| 平台域 | `joinquant_strategy/` | 面向聚宽平台的策略集合；后续若有其他平台可并列新增目录 |
| 风格域 | `small_cap/` | 小市值相关策略；同风格新策略放此目录下 |
| 策略脚本 | `*.py` | 单文件策略，含选股、交易、风控与日志 |

命名约定：

- 目录优先用英文风格标签（如 `small_cap`）
- 策略文件用功能关键词：`margin`（融资）+ `leverage`（杠杆）

## 策略一览

### `joinquant_strategy/small_cap/margin_leverage_strategy.py`

**小市值融资杠杆策略 / Small-Cap Margin Leverage**

在主板小市值股票中，结合短期趋势、流动性与融资余额情绪选股，等权持仓，并用多层止损与组合回撤空仓控制风险。

#### 调度时段

| 时间 | 函数 | 作用 |
|------|------|------|
| `before_open` | `select_candidates` | 开盘前选股（用前一交易日数据） |
| `09:30` / `open` | `my_trade` | 先执行待卖出，再买入候选 |
| `12:20` | `select_candidates` | 午间备用选股（逻辑同开盘前） |
| `15:35` | `calc_sell_list` | 收盘后计算次日待卖出（需**分钟**回测频率） |

#### 选股流程

1. **基础过滤**：流通市值 50～150 亿；剔除 ST、科创板、创业板、北交所  
2. **数据充足**：价格序列长度足够  
3. **趋势**：收盘价 > 15 日 EMA  
4. **流动性**：20 日日均成交额 ≥ 1.5 亿  
5. **融资情绪**：融资余额日增幅 > 5%  
6. **波动**：近 4 日振幅 < 7%  
7. **买入**：取前 5 只，每只约 20% 仓位  

#### 卖出与风控

- 单票亏损金额 ≥ 组合总资产的 1.5% → 止损  
- 持有期最高价 − 2×ATR(14)，收盘跌破 → 跟踪止损  
- 每满 5 个交易日检查是否突破「成本 + 2×N×买入时 ATR」；未突破则卖出  
- 组合收益从峰值回撤 ≥ 10 个百分点 → 清仓并空仓约 10 个交易日  

卖单在 15:35 标记，次日开盘执行（受 T+1 约束）。

#### 主要函数

| 函数 | 说明 |
|------|------|
| `initialize` | 基准、交易成本、滑点、参数与定时任务 |
| `select_candidates` | 选股漏斗；输出筛选数量与入选个股指标卡片 |
| `calc_sell_list` | 收盘后风控与待卖出列表 |
| `my_trade` | 早盘先卖后买 |
| `_log_recommend_cards` | 打印最终入选股票的全部考察指标 |
| `_log_section_banner` | 各时段日志大标题（适配聚宽「新在上」日志） |

#### 关键参数（`g.*`）

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `min_circ_mv` / `max_circ_mv` | 50亿 / 150亿 | 流通市值区间 |
| `min_avg_amount` | 1.5亿 | 20 日日均成交额下限 |
| `ema_period` | 15 | EMA 周期 |
| `vib_period` / `max_vib` | 4 / 7% | 振幅窗口与上限 |
| `min_margin_increase` | 5% | 融资余额日增幅下限 |
| `max_positions` / `position_pct` | 5 / 20% | 持仓只数与单票仓位 |
| `loss_threshold_pct` | 1.5% | 单票亏损占组合比例止损 |
| `cycle_days` | 5 | 成本区验证周期 |
| `drawdown_empty_pct` / `empty_days` | 10点 / 10日 | 组合回撤空仓 |

## 使用方式

1. 打开聚宽「策略」编辑器  
2. 将对应 `.py` 全文粘贴并保存  
3. 回测频率选择**分钟**（否则 `15:35` 的 `calc_sell_list` 不会按预期执行）  
4. 模拟/实盘更新代码后如遇 `g` 属性缺失，需重启策略使 `initialize` 重新执行  

## 后续扩展建议

可在同层继续扩展，例如：

```text
joinquant_strategy/
├── small_cap/          # 小市值
├── mid_cap/            # 中市值（预留）
└── index_enhance/      # 指数增强（预留）
```

每个风格目录下保持「一策略一文件」，便于在聚宽单独粘贴运行。
